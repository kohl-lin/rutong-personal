# Career Materials Rules

处理 Rutong 的职业定位、简历或面试材料时：

1. 先读当前履历事实库、appraisal、工作记录和项目证据，再写正式版本。
2. 正式职位使用 `Business Intelligence`；功能定位可根据目标岗位使用 `AI Strategy & Transformation` 或 `AI Portfolio Management / PMO`，两者不互相替代。
3. 只把 `已确认` 内容写成事实；`候选表述`、`待确认` 和 open question 保持显式状态。
4. 分开个人直接交付、个人设计或运营的机制、组织 adoption / impact，以及 Portfolio scope。范围数字不能单独证明个人 ownership 或价值。
5. 对部署、当前在线、活跃使用、ROI 等易变化 claim 做当次验证；无法验证时说明证据日期和限制。
6. 先形成 evidence-rich inventory，再按目标岗位和篇幅压缩，避免为了简洁丢掉 attribution 与 caveat。
